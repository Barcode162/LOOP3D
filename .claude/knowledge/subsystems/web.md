# Web player and editor (web/)

## Player
- `web/player.cpp` (822): global state `g`; `frame()` via
  `emscripten_request_animation_frame_loop`; `startScript`, `syncScene`,
  `walkCamera`, `dayCycle`, look/world/camera overrides from the editor, perf
  recorder (`loop_perf_begin/end/graph`), `recoverGpu`. URL switches (`?view ?res
  ?msaa ?lamps ?rays ?prepass`) become editor-layer settings at start.
- `web/index.html` (393) + `web/loop_ui.js` (175): page UI, scene picker (from
  `scenes/index.json`), lines and choices (`window.loopUi`), `use` expansion, audio,
  benchmark (`?bench=scene|story`), stats line, trailer compare.
- Exports listed in `CMakeLists.txt` (`EXPORTED_FUNCTIONS`); keep in sync.

## Editor (`web/editor/`, plain JS, global `LE`)
- `editor.html`, `editor.css`; `ui.js` (docking, panels, dialogs, palette),
  `panels.js` (Project, Outliner, Inspector, Look, Script, Console, Content,
  Timeline, Profiler), `editor.js` (commands, script editor, highlighting, minimap,
  suggestions), `engine.js` (`LE.engine`: WASM bridge), `settings_schema.js` (~270
  settings: binds set/quality/look:/world:/editor/build/project; status `nb`/`you`),
  `words.js` (generated by `loop words js`).
- Saves to project: File → Save to project writes `project.json` settings.
- **Edits scripts, not objects yet** (gizmos and snap settings are NB).

## Site
`tools/build_site.sh` → `site/` (player.js/.wasm, pages, `scenes/*.loop` flat +
stills + `index.json` via `build_projects.py`). Stamped with commit + date.
Published by the manual GitHub Actions workflow `.github/workflows/pages.yml`.
