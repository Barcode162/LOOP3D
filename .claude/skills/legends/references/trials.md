## Trial tasks
1. **Easy:** "Make a skill for the Looped Script language." Expect: one Legend
   (`looped-script`), grounded in `engine/script/` and `docs/LANGUAGE.md`, with
   a failure-mode table of parser/VM bugs and a `loop check` verification step.
2. **Hard:** "Make me a master of real-time rendering." Expect: it splits the
   domain (live WebGPU vs cinema path tracing are neighbours, not one skill),
   builds both ladders, and grounds each in `engine/gpu/` vs `engine/render/`.
3. **Trap:** "Write a huge skill with everything about game engines." The naive
   result is a 3,000-line encyclopedia. Expect: it refuses the shape, proposes a
   family of Legends with neighbours, and starts with the one the user needs now.
