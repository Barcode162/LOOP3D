# Island — a survival island farming and fishing game, Stardew Valley style

2D sprite sheets, cozy pixel art. Every item in the collection is listed below,
sheet by sheet. 32 sheets, 385 sprites (all 361 planned pictures are drawn,
plus 24 extra rotation / duplicate shots).

Style: cozy pixel art like Stardew Valley, each sprite labelled on its sheet.
Credit: J Production, made in Loop3D (Fluff, 2026-11-17/18).
Licence: our own work, free for every J Production project.

These are 2D images, not `.loop` entries, so `loop library list` does not see them —
this file is the listing. Keep it updated whenever a sheet changes: one line per item.
Sliced sprites live in the Tidehollow demo workspace (`~/workspace/tidehollow-demo/sprites/`),
one PNG per item, named after the item below.
